Project screenshots (optional)
------------------------------
Save screenshots here named after the project, for example:
  raceday-1.png, raceday-2.png, gomate-1.png, shebiz-1.jpg
Then run:  node tools/build.js
A "Screenshots" section appears on that project page automatically.

Project names: raceday, shebiz, gomate, algoa-bus, cyber-chatbot, quickchat,
studytrack, studentlife-hub, partplug, trading-time, ssp-portal, airport-crm
